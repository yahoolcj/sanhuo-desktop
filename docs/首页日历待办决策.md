# 首页日历待办决策

记录日期：2026-09-18

## 已确认

### 领域口径

- “有待办的日期”仅统计订单状态为 `todo`（待办）的商单；不包含待发布、待结款和已完成。
- 商单按其“时间”字段所属的自然日归入日历。
- 未排期（时间为空）的待办商单不显示在日历中。
- 同一天的多笔待办不在日期格中显示数量。

### 月份与视觉

- 首页日历默认显示系统当前月。
- 支持切换上个月和下个月；浏览月份仅在内存中存在，刷新页面后回到系统当前月。
- 今天使用主题绿色背景高亮。
- 有待办的日期使用主题绿色文字。
- 今天有待办时，上述背景高亮与绿色日期文字同时保留。

### 弹窗与首页结构

- 点击有待办的日期，打开“日历待办列表”弹窗，仅展示该日期、状态仍为待办的商单。
- 弹窗为只读预览，列出项目名称和时间，并提供“去待办看看”跳转至待办页的入口；列表项不直接进入编辑。
- 日历卡片位于首页状态总览下方。
- 现有“待办商单”预览卡片暂时隐藏，不删除数据和现有渲染逻辑。

## 待决策

- 空日期是否允许点击，以及点击后是否展示空态弹窗；建议不可点击，避免无意义操作。
- 日历周起始日使用周日还是周一；建议沿用系统常见的周日开头，并与现有“周日—周六”星期文案保持一致。
- 同一天多笔待办在弹窗内的排序规则；建议按时间升序，未提供具体时间的商单排在末尾。
- 跨月补位日期（上月末、下月初）是否展示；建议显示为弱化文字，便于用户识别完整周结构，但不可点击。

## 不创建 ADR 的原因

以上均为可快速调整的首页展示和交互约定，不属于难以逆转的架构决策。
