# Issue 001：确认日历待办的剩余交互口径

## 父单

[首页日历待办功能 PRD](../首页日历待办功能PRD.md)

## 要做什么

确认首页日历待办中尚未定稿的四项表现规则，使后续实现无需将建议方案误当作产品决策：空日期操作、一周起始日、同日多笔待办的排序、跨月补位日期的展示。

## 验收标准

- [ ] 已确认无待办日期是否可点击及其反馈方式。
- [ ] 已确认日历首列为周日或周一。
- [ ] 已确认日历待办列表内同日多笔商单的排序规则。
- [ ] 已确认是否显示上月末、下月初的补位日期及其可点击性。
- [ ] 已将确认结果同步回父 PRD 的“待产品确认”项（仅更新相应 TODOQ 或经明确授权修订正文）。

## 阻塞于

无 — 需要产品确认后才能开始后续实现。
