# Issue 002：首页日历待办总览

> 类型：AFK
> 版本：1.0.0
> 覆盖用户故事：1、2、5

## 父单

[首页日历待办功能 PRD](../首页日历待办功能PRD.md)

## 要做什么

在首页状态总览下交付可浏览的月历待办卡片：默认显示系统当前月，可前后切换月份；从现有订单实时派生日期标记，仅标记已排期且状态为待办的商单。首页原“待办商单”预览卡片隐藏但保留，今天和有待办的日期按已确认主题绿色规则呈现。

## 验收标准

- [ ] 首页状态总览下显示日历待办卡片，原首页待办预览不再可见，待结款卡片保持可用。
- [ ] 卡片默认显示系统当前月，可跨月、跨年切换；刷新后恢复系统当前月。
- [ ] 仅状态为 `todo` 且时间合法的订单标记对应日期；未排期或其他状态订单不标记。
- [ ] 日期格不显示待办数量；有待办日期为主题绿色文字，今天为主题绿色背景，两者可叠加。
- [ ] 浏览月份不写入 localStorage，订单存储结构与旧数据兼容不变。
- [ ] 所有变更的核心静态资源已对应更新 Service Worker 缓存版本，离线刷新仍可打开应用。
- [ ] 在 390×844 手机全屏和桌面居中画布中，五行、六行日历均不遮挡后续内容。
