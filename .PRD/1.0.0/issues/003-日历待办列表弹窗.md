# Issue 003：日历待办列表弹窗

> 类型：AFK
> 版本：1.0.0
> 覆盖用户故事：3、4、5

## 父单

[首页日历待办功能 PRD](../首页日历待办功能PRD.md)

## 要做什么

让用户点击有待办的日期，查看仅属于该自然日、当前状态仍为待办的商单只读列表。弹窗展示项目名称和时间，提供进入待办页的入口；不在弹窗内编辑订单。

## 验收标准

- [ ] 点击有待办日期会打开日历待办列表弹窗，点击无待办日期遵循 Issue 001 确认的规则。
- [ ] 弹窗只列出该自然日内状态仍为 `todo` 的商单，并显示项目名称与时间。
- [ ] 同日多笔商单按 Issue 001 确认的排序展示；状态推进后刷新视图，列表与日期标记同步移除该商单。
- [ ] “去待办看看”关闭弹窗并切换至待办页；列表项没有编辑入口。
- [ ] 关闭按钮和遮罩均可关闭弹窗，用户文本均经过 HTML 转义。
- [ ] 修改核心静态资源后已更新 Service Worker 缓存版本，并完成在线、离线手工回归。
